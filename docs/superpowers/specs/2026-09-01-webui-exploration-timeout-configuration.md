# WebUI 页面探索超时配置

本方案将单次模型请求超时与页面探索总时限彻底分离，并允许用户为每次脚本生成任务覆盖探索总时限。

## 配置语义

- `AITS_LLM_TIMEOUT_SECONDS` 只控制一次 LLM API 请求的最长等待时间，默认建议为 300 秒。
- `WEBUI_EXPLORATION_TOTAL_TIMEOUT_SECONDS` 只控制一次 WebUI 页面探索阶段的总时限，默认 600 秒。
- 两个配置互不回退。探索总时限配置无效时回退 600 秒，并统一限制在 60 至 1800 秒。

## API 与任务快照

- 项目级生成设置接口返回当前服务器默认探索时限以及允许的最小值、最大值。
- 创建生成任务可选传入 `exploration_timeout_seconds`；未传时由后端采用当前服务器默认值。
- 新任务始终保存实际生效值，确保暂停、恢复及异步执行不会因后续修改 `.env` 而改变。
- 历史任务保持空值；继续执行时采用当时进程读取到的服务器默认值。
- 后端始终校验 60 至 1800 秒，不能依赖前端输入约束保证安全。

## 前端交互

- “探索并验证测试流程”页面增加“页面探索总超时时间（秒）”数字输入框。
- 页面加载生成设置后预填服务器默认值，步长为 60 秒，并显示有效范围和“仅影响本次任务”的说明。
- 设置接口加载失败不阻塞生成：输入保持为空，创建请求省略该字段，后端继续使用服务器默认值。

## 执行与兼容

- Worker 从生成记录读取任务快照并传给 MCP 页面探索器；仅历史空值任务读取服务器默认值。
- 此参数只覆盖页面探索阶段，不覆盖需求理解、脚本生成、校验、修复或单次 LLM 请求超时。
- 数据库变更仅新增可空正整数字段，不修改或删除历史数据。

## 验收与部署

- 后端测试覆盖配置独立性、非法配置回退、创建默认/覆盖/边界、设置接口和 Worker 参数传递。
- 前端测试覆盖服务器默认值预填、用户覆盖、加载失败回退及创建请求字段。
- 运行 Django 迁移、后端离线回归、前端单元测试和生产构建。
- 部署后重启 Django 与 Celery；开发模式前端刷新页面即可。
