# WebUI 目标范围内探索与模型故障处理

本次范围已由用户批准：测试环境的普通 CRUD 不再全局只读。此文更新先前方案中“探索绝不写入”的规定，其他工作区、人工调试和保存规则不变。

## 执行边界

- 理解目标 → 按目标探索并验证流程 → 根据证据生成 Python 草稿 → 用户检查、明确发起调试 → 保存用例。
- 默认只创建、修改、删除本次尝试生成的唯一测试数据；每次探索使用独立命名空间。用户明确指定已有记录时，不能扩大操作范围。
- 用户描述中的明确只读或禁止操作仍有效。只读探索只能证明页面结构和定位证据，不能宣称已验证业务提交。
- 普通 CRUD 的旧暂停记录无需改写成只读即可继续。审批、支付、发布及未授权文件/外部消息操作不在本次支持范围；新拦截使用 `EXPLORATION_EXTRA_RISK_BLOCKED`，页面提供描述编辑入口。
- `playwright_evaluate`、文件上传、智能体主动关闭会话仍禁用；保留原有预算、取消、登录失败、连续交互失败和重复操作保护。

## 证据与清理

`ExplorationSnapshot` 增加操作台账、命名空间与清理状态，字段保存在现有 JSON 中，无新增数据库迁移。平台回调统计潜在/已拦截写入调用；AI 整理业务操作和结果，两者分开展示，工具调用成功不等于业务断言成功。

补充探索沿用同一会话与总预算，只补缺失证据或清理，不重复已完成提交。清理分为无需、未尝试、已清理、存在残留、未知；残留和未知不得当作成功。模型中断保留已经解析的证据和平台计数，可能写入后中断时提示人工检查；不能承诺尚未生成的草稿存在。

生成草稿每次正式运行重新创建唯一数据，不能复用已清理的探索记录。探索完成不等于 Python 脚本调试通过。

## 不重复执行

同一生成 revision 使用数据库行锁与工作区内的持久执行声明。重复投递和过期任务不重新进入浏览器。worker 崩溃后不自动从头重放；需用户检查数据状态，取消旧任务并明确新建任务。该机制减少重放，不是外部业务操作的事务或回滚保证。

可识别提交发生工具错误或超时后停止本轮，不再让智能体重试该提交；未确认的操作结果和清理状态保留为未知。

## 模型供应商故障

日志中 `/chat/completions` 确实返回了 500、503、504，且 SDK 已进行有限请求重试。新增分类从可信 SDK 异常链或明确的模型调用边界读取状态码，向页面区分服务异常、网关超时、限流和认证问题，不根据任意浏览器错误里的数字推断模型故障。

本次不切换供应商、不增加整个探索流程重试、不修改 SDK 的重试配置。HTTP 重试只能缓解瞬时故障，不能修复供应商稳定性。模型服务失败后应先看本轮操作/清理状态，再决定是否新建任务。

## 验收与上线

- 本次验收：后端 275 项离线测试、前端 18 项测试通过；生产构建通过，仍有原有的大包体积提示。浏览器 skill 用于本地模拟组件页的交互和排版检查；未执行真实业务站点生成/调试。
- 后端使用 `backend/.venv/bin/python backend/scripts/test_webui_generation_offline.py`：SQLite 内存数据库、内存缓存/队列，并阻止网络连接；包含模型 mock 和 SDK mock transport 验证。
- 前端运行 `npm run test:unit`、`npm run build`；使用本地模拟组件页检查输入、台账、残留提示和描述编辑，不提交真实生成。
- 重启后端及 Celery 生效；`npm run dev` 刷新页面即可，生产前端需更新构建产物。本次无需数据库迁移。
- 回退仅需恢复本次代码提交；新增 JSON 字段有默认值，回退不会撤销探索阶段已经写入的业务数据，残留需人工处理。

## 已知限制

通用 MCP 的 selector/click 元数据不能证明数据库行归属，也不能可靠识别所有自定义按钮的副作用。可识别的禁止动作由代码拦截，任意网页的数据范围仍依赖用户约束、智能体遵守指令和操作证据；不是完整的网页写入沙箱。请先在隔离、可清空的测试环境试跑，不以模拟测试代替真实站点验收。
