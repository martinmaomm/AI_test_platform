# API/Web 项目名称编辑设计

## 背景

API 测试项目和 Web UI 测试项目创建后，项目卡片只有“进入工作区”操作，没有修改名称的入口。后端项目 ViewSet 已支持更新，但前端列表页没有调用入口。

## 目标

- 在 API 项目列表和 Web 项目列表的项目卡片上增加“编辑项目”入口。
- 通过弹窗修改项目名称和项目描述。
- 复用现有项目更新接口，不新增数据库字段或迁移。
- 保存成功后刷新列表；如果编辑的是当前项目，同步刷新当前项目状态。

## 方案

- 前端：在两个项目列表页复用一致的编辑弹窗、表单校验、提交状态和错误提示。
- API：使用项目详情更新端点的 `PATCH /projects/{id}/`，只提交 `name` 和 `description`，避免覆盖其他字段。
- 后端：保留现有 `ProjectDetailSerializer` 的字段约束，并补充项目名称去除首尾空白及非空校验；更新权限沿用项目成员的 `can_edit` 语义。
- 兼容性：不改变项目类型、不影响项目数据、环境、用例和知识库关联。

## 错误处理

- 名称为空或长度不符合现有规则时，前端阻止提交。
- 后端校验失败时，前端显示接口返回的错误信息。
- 保存期间禁用提交按钮，避免重复请求。

## 验证

- 执行 Django `check`。
- 执行前端生产构建。
- 手动验证 API 和 Web 项目分别修改名称、取消编辑、保存失败和当前项目同步场景。
