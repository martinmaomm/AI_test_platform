## 平台切换

切换前确认没有活动压测，并在私有临时目录保存 `.env` 备份。原后端进程加载 `0.3.0`，真实配置接口返回“发行包固定运行时哈希与当前平台不匹配”。

将本机 `PERFORMANCE_NODE_RELEASE_DIR` 更新到 0.3.1 发行目录，先验证 Caddy 配置，再核对原进程 PID、启动时间、命令和工作目录，依次正常停止旧控制器、后端和 Caddy，通过平台管理器启动新实例。沿用现有 CA、监听配置、数据库和节点身份；未重启 Celery。

切换后验证：

- 真实 HTTP 配置接口返回 `agent_version=0.3.1`、`installation.available=true`、空错误原因，支持 amd64 和 arm64，控制器在线且执行入口可用。
- 后端、控制器、Caddy 健康检查通过；Celery 原实例仍健康。三个新进程均使用新的发行目录。
- 严格校验 TLS 的 CA 入口正常；两种 0.3.1 归档的 HTTPS HEAD 均返回 200，长度与 manifest 一致。
- 现有待安装节点的安装信息接口可用；旧 0.3.0 节点明确提示需要升级。
- 已通过真实注册凭证接口为现有待安装节点重新生成 0.3.1 安装命令。含凭证的命令仅写入本机私有临时文件，权限为 0600，不进入 Git、验收文档或公开镜像；凭证有效期 15 分钟，过期后须在页面重新生成。
