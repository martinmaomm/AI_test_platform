## 🔧 技术细节

### 数据提取逻辑

1. **提取端点信息**
   - 从 `test_data.teststeps` 中遍历每个步骤
   - 提取 `request.method` 和 `request.url`
   - 去重并格式化为 `[{"method": "POST", "path": "/api/user/login"}]`

2. **提取模块信息**
   - 从端点路径中提取模块关键词（如 `/api/user/xxx` → "用户模块"）
   - 支持多种模块映射：user→用户模块, building→楼栋模块, community→小区模块等

### 数据存储

- **involved_endpoints**：JSON 字段，存储端点列表
- **involved_modules**：JSON 字段，存储模块名称列表
