# AI 测试平台性能节点

**仅限测试使用 / For authorized testing only. Not for production.**

这是开发中的独立性能测试节点，不是整个平台，也不是生产发行版。仅可用于已获明确授权的测试目标；请从低负载开始，不得压测未获授权的网站或服务。

## 镜像内容

- 性能节点 Agent `0.3.0`，节点管理协议 `2`，请求快照协议 `2`；原 `0.2.x` 镜像保留，不自动升级已安装节点。
- 固定版本 Locust `2.43.3` 和 stunnel，支持 Linux amd64、arm64。
- 非 root 用户运行；平台安装器使用只读文件系统、资源限制和独立身份卷，不挂载 Docker socket。
- 不包含平台配置、API 密钥、节点注册凭证、业务数据库、运行日志或证书私钥。实例身份在运行时登记生成，不随镜像分发。
- 支持虚拟用户独立会话、准备步骤、每轮唯一变量、响应提取与严格类型业务断言。先进行单用户验证，再执行正式负载；网页探索和计划编辑本身不会发起压测。

## 安装

在 AI 测试平台的“性能测试 → 节点管理”添加节点，复制平台生成的安装命令，在已安装 Docker 的 Linux 主机以 root 身份运行。

网页提供一条 `docker run`，引用固定多架构索引摘要，Docker 自动选择 CPU 架构。镜像的 `start` 命令通过 HTTPS 注册节点并持续运行；重启复用独立卷内的身份，不再次消费注册令牌。仅拉取镜像不会连接任何平台。

安装需要平台签发的有效一次性注册令牌。令牌会在终端历史及 Docker 容器参数中可见，注册后失效；不要公开分享安装命令、`docker inspect` 输出或身份卷。长期身份不在容器参数、环境或日志中。

私有 CA 使用管理页面提供的短 SHA256 指纹：容器仅取回公开 CA，校验指纹及合法性后再以严格 HTTPS 发送身份请求；无需复制证书全文，更不需要平台私钥。公共 CA 使用系统信任。

运行节点需要能通过 HTTPS 访问平台，执行压测时还需连接平台配置的 mTLS 端口。公网节点无需开放入站端口，不需要 VPN。

## 版本与数据

镜像使用带版本、架构和内容摘要的标签，另提供双架构索引；平台实际使用 `@sha256:…` 固定引用，不跟随浮动标签自动更新。长期身份和执行状态只保存在节点独立卷中，重启时请保留。重复 `docker run` 不覆盖同名容器，请使用 `docker restart`。平台吊销节点不会删除宿主机上的容器和卷。

此镜像未承诺生产可用性；请自行评估测试目标授权、网络、数据和负载风险。
