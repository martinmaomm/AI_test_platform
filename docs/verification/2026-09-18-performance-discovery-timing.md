## 行为调整

- 性能网页探索页面默认 900 秒；创建 API 未传时也默认 900 秒，服从服务器更低的上限。

- 防止持久化检查点按墙钟时间提前停止暂停中的任务；确认结束与取消同时发生时仍停止后续操作。
- 认证 scheme 仅返回白名单类型，非标准拼接或纯凭证返回 `unknown`；旧样本读取和交接也进行安全投影，不批量改写数据库。
- 优先读取响应体，缩短导航前可读取窗口；记录受控读取阶段和错误分类，并在性能样本详情展示中文原因。没有重放登录或补发网站请求。
