# 性能节点一键接入（方案 B）实施计划

用户已确认实施。保留现有单节点顺序执行、每轮 mTLS、项目权限和一次性登记语义，只补安装接入层，不重构压测引擎。

## 用户体验

1. 平台管理员在项目内添加节点：名称、内网/公网；标签放入高级选项。
2. 安装向导提供 Linux Docker 安装命令、条件说明、失效时间和复制按钮。
3. 用户在远程 Linux 终端执行；检测环境、下载固定版本镜像、登记、启动独立容器。
4. 页面根据真实数据显示等待安装、已注册等待心跳、在线；不虚构下载/安装进度。
5. 已有节点可重新打开指导；不会因为查看页面而重置身份。重置需确认，命令和凭证不持久化到浏览器。

## 接口与发布契约

- 登记/重置响应保留原字段，追加 `installation`；只在持有本次一次性凭证时返回安装命令。
- `GET nodes/<uuid>/installation/` 返回 `{node, installation}`，只允许本项目有权限的平台管理员；不回显旧凭证/命令。
- 节点追加只读 `registered_at`；config 追加安装可用性。缺发布资源不能显示假可用命令。
- `PERFORMANCE_NODE_PUBLIC_URL` 固定可信 HTTPS 地址，不从不可信 Host 推导。
- `PERFORMANCE_NODE_RELEASE_DIR` 下 manifest.json 描述版本、协议、引擎、固定脚本摘要和各架构镜像；镜像由受控发布过程生成。
- 可选 `PERFORMANCE_NODE_CA_CERT_FILE` 只允许 CA 公钥。私有 CA 从可信管理页面带入安装命令，绝不关闭证书校验。
- 通用安装器：公开 `GET /api/v1/performance-agent/install/install.sh`。镜像由 Caddy 仅对限定路径提供静态下载，避免 Django/ASGI 缓存大文件；不公开整个 backend/resource 或 temp。
- Bootstrap 创建私有临时目录，嵌入 CA、临时凭证，校验 HTTPS 和安装器 SHA256 后执行；选择已发布的 Linux amd64/arm64 镜像。
- 安装器参数固定：`--platform --node-id --token-file [--ca-file] --image-ref --image-id --image-config-id --archive-url --archive-sha256 --archive-size`。固定镜像 digest/ID 与归档摘要都要验证；同时记录 OCI ID 和归档内 config 的实际内容摘要，适配 Docker containerd/classic 存储，不接受其他镜像身份。

## 安装与安全边界

- 使用现有 Docker；缺少 Docker 时给出明确指导，第一版不静默安装/升级宿主机软件。
- 检查本机 Linux、架构、权限、必要工具和本地 Docker daemon；不向意外的远程 Docker context 安装。
- 节点 UUID 派生独立目录/容器/网络/身份卷，资源所有权校验和安装锁；重复执行不重新登记，不覆盖其他项目或业务容器。
- 命令含短期安装凭证，有效期内仍属敏感信息；不写 URL、访问日志、容器环境或永久脚本。
- 镜像必须先验证再导入；容器只读、非 root、无 Docker socket、无发布端口、限资源和日志轮换。
- 登记失败不盲目重试；已保存身份优先保留恢复。停止/重启节点不自动重放任务。
- 当前注册15分钟超时保持不变；慢下载导致凭证过期需明确提示刷新凭证，缓存镜像应可复用。
- 本轮不新增 SSH 托管凭证、全局节点池、多节点压测、Mac开机自启或服务器系统升级。

## 分工

- 主 Agent：契约、镜像发布工具/资源、Caddy、配置、文档、集成验收及中文提交。
- Sol：后端权限/安装信息/命令生成与测试。
- Sol：Bash 安装器、冲突/恢复/失败测试。
- Terra：节点接入 UI、复制回退、状态轮询与前端回归。

## 验收

1. 后端权限隔离、只在登记返回秘密、版本/路径/CA/参数校验和配置缺失提示。
2. 安装器模拟集成：新安装、幂等、无Docker、冲突、坏摘要、网络失败、身份保留与不泄密。
3. 前端测试/build：安装向导、非安全上下文复制、真实状态、过期、项目切换、防误重置。
4. 使用已授权 VPS 建立独立验收节点，不触碰先前在线节点和原有容器；从网页生成的命令完成下载/登记/在线，重复执行不改变身份。
5. 对专用临时目标做1用户、最多5秒验证并核对计数；不压NAS/商城。完成后停止本轮临时目标并说明留存资源。
6. 后端/Celery空闲时重启，确认普通UI/API未因安装入口受影响；提交源码/文档，不提交镜像、密钥、.env、浏览器归档或其他未跟踪文件。
