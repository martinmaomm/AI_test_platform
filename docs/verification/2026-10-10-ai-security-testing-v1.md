# AI 辅助网站与 API 安全测试首版验收

## 实施范围

- 独立 `security` 项目类型、首页入口、计划和任务页面。
- 手工或选择式来源导入 → 测试范围与 A/B 账号 → 规则/AI 生成检查项 → 勾选执行 → 中文证据卡片 → 单文件 HTML 报告。
- 四类受控 GET/HEAD 检查：认证、资源越权、响应信息、安全配置。第一版不执行自动登录、写入或注入探测。
- 凭据加密保存；模型只接收候选编号及认证意图；账号切换不继承基准身份；URL 认证参数和相同 A/B 凭据不产生越权误判。
- 固定 DNS 地址、HTTPS 主机校验、私网开关、禁止元数据地址、禁止环境代理和重定向。请求预算、速率、读取长度、单请求与总时限均有边界。
- 任务采用固定快照和幂等请求编号，重复消息不重放请求；旧版本生成不能覆盖已编辑计划，撤权/取消/超时有终态；AI 阻塞调用运行于可终止子进程，适配当前 Celery solo 模式。

3. AI 规划测试使用受控输出和本地子进程替身，验证未知检查项/非法 JSON 拒绝、阻塞超时、取消和父进程消失后的清理。未向真实模型发送请求。
   中断验收还覆盖完成首项后的取消与总超时：数据库及 HTML 保留已完成项、最新请求计数和未完成说明，额外原始字段及测试凭据不泄露。
4. 前端全量 `npm run test:unit`：**422 项通过**。本次开放安全入口后同步首页断言，并修正技术债中记录的网页探索旧文案断言；没有改变网页探索生产行为。
5. `npm run build` 通过。仍有既有 Monaco 等大包警告，没有新增编译错误。
6. Chrome 真实渲染、API 全拦截为替身：新建计划、保存、规划完成后的刷新竞态、勾选执行、证据展开、HTML 下载全流程通过；无页面异常、无意外网络请求。凭据输入和提交不写浏览器持久化存储。
7. 真正的报告生成器输出文件后，以本地文件方式在 Chrome 打开；中文排版、证据和截断说明正常，无脚本/图片/外链，无外部网络请求。输入 HTML 转义显示，额外原始字段不导出。

## 本机激活

- 先执行 `./platform stop controller caddy`，只保留后端 ASGI（HTTP/WebSocket）及 Celery。
- 迁移前确认 Celery active/reserved/scheduled 均为 0。迁移计划只有 `projects.0007_alter_project_project_type` 和 `security_testing.0001_initial`，两项已成功应用。
- 仅执行 `./platform restart backend celery`。两项健康；controller 与 caddy 均保持停止。已有前端开发服务保留，验收使用的临时 5174 服务已停止。
- 实际认证 HTTP 读取：安全项目列表返回 200；安全路由不存在项目返回 404。Celery 注册表存在 `security_testing.tasks.run_security_task`。
- 迁移前后既有数量一致：项目 4、性能计划 3、性能运行 17、性能节点 13。没有创建真实安全计划/任务或对历史性能记录发起运行。
- 数据库的 RAG 条件唯一约束兼容警告为既有 MariaDB 提示，本次迁移没有触及 RAG 模型。

## 验收边界

上述证据证明隔离条件下的功能链路和本机服务激活，不代表已完成真实目标漏洞验证、真实模型效果或生产容量验收。实际接口的账号、资源归属和证据字段需由使用者配置；不把 HTTP 200 或相同公共内容当成漏洞。

第一版仅导出已保存的有限证据，不保证覆盖所有业务权限或敏感信息。含任务的安全项目及关联计划暂不允许删除，以保留证据。回退代码时保留新增表及用户数据，不自动执行删表或删除历史记录。
