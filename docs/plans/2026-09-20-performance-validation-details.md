# 单用户验证逐步明细

单用户验证用于调试计划：一个虚拟用户先执行准备步骤，再执行一轮主流程。当前仅有聚合统计和最多 20 条失败样本，无法查看完整响应及未执行步骤。

## 本次范围

- 仅单用户验证记录逐步结果：阶段、成功/失败/跳过、实际请求 URL、渲染后的请求参数、响应状态/耗时/正文、每条断言的结果和期望/实际值、提取结果。
- 保持当前断言、步骤中断和执行策略。断言失败仍中止本轮；提取失败不提交该步的任何提取值，后续步骤明确显示跳过。
- 节点在内存中脱敏后上报有界明细，沿用既有加密通道和固定执行模板；后端再次限制结构与体积。明细只保留于最新指标，避免重复存入每个趋势采样；只有现有 REPORT 权限的详情接口返回它，列表接口不返回正文。
- 密码、令牌、Cookie 等敏感字段和已知凭证值脱敏；超长、读取不完整的响应明确标注。历史记录不编造正文，展示已有失败证据并提示重新进行单用户验证。
- 不修改计划数据，不自动对实际目标发请求，不部署远端节点。固定模板改变后，平台和节点需同步更新；沿用模板逐字节校验，禁止远端下发任意代码。
- 节点版本提升到 0.3.1；0.3.0 仍可上报心跳，但创建运行会明确提示升级，避免旧节点进入运行后才报固定模板不匹配。管理协议与快照协议仍为 2。镜像发行和现场节点升级不自动执行。

## 验证

使用临时数据库、回环 HTTP 夹具、真实节点和执行器验证通过/失败/跳过、断言与提取、脱敏与截断、单轮结束及正式压测仍只汇总统计；浏览器验证明细、旧记录提示和权限边界。更新节点及真实目标的验收单独记录，不将本机夹具通过视为线上验收。
