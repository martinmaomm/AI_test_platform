# 用户管理与项目分配

第一版只有“管理员”和“普通用户”两个可选角色。平台初始化的超级管理员账号受保护，可以设置管理员身份，不需要再建立一套自定义角色。

## 使用方法

1. 管理员从首页进入 **全局系统设置 → 用户管理**。
2. 点击 **创建账号**，填写用户名、邮箱和至少 8 个字符的密码。管理员只能创建普通用户；超级管理员可以选择管理员或普通用户。
3. 在普通用户所在行点击 **分配项目**，勾选需要协作的项目并保存。可以分配多个项目，一个项目也可以分配给多人；取消勾选表示撤销该项目的成员资格，全部取消表示不分配任何项目。
4. **编辑/重置密码** 可以修改普通账号、启停账号或设置新密码；密码留空保持原密码。本版不删除账号及其历史执行记录。

## 权限边界

| 操作 | 超级管理员 | 管理员 | 普通用户 |
| --- | --- | --- | --- |
| 管理 AI 实验室、全局系统配置 | 可以 | 可以 | 不显示入口，后端也拒绝访问 |
| 创建、编辑、删除项目 | 全部项目 | 全部项目 | 不可以 |
| 分配普通用户的项目 | 可以 | 可以 | 不可以 |
| 生成、维护、调试、运行测试内容 | 全部项目 | 全部项目 | 已分配的项目 |
| 设置/取消管理员身份 | 可以 | 不可以 | 不可以 |
| 打开独立测试报告与截图 | 公开只读 | 公开只读 | 公开只读，未登录也可访问 |

普通用户可以使用管理员启用的共享模型生成用例，但不能读取密钥或修改模型/MCP/RAG配置。已保存的项目测试内容按项目协作，不限创建者；个人草稿和对话仍是个人工作上下文。

管理员无需分配项目，默认管理全部项目。普通用户新注册后不自动加入项目，由管理员分配。移除成员、降级角色或停用账号后，新请求按最新权限检查；不能以此撤销已经发生的测试网站操作。

本人和超级管理员账号在用户管理中显示为受保护账号，个人资料和自己的密码通过个人资料入口修改。普通管理员不能重置另一个管理员的密码或停用其账号。

个人资料页仅保留用户名（只读）、邮箱和修改密码；不再显示手机号、姓名拆分、头像上传、个人简介、职位、部门、公司及技能标签。修改邮箱不会清空这些历史资料，数据库无需迁移。
