# 场景测试用例 - 涉及端点摘要显示问题排查指南

## 问题描述
场景测试用例列表页的"涉及端点摘要"列显示"无摘要信息"，无法显示每个端点的摘要字段。

## 已实施的修改

### 1. 后端修改 (`backend/apps/api_testing/serializers.py`)

添加了 `involved_endpoints_with_summary` 字段，该字段会：
- 读取测试用例的 `involved_endpoints` 数据
- 根据 `method` 和 `path` 查询 `APIEndpoint` 表
- 支持多种匹配策略：
  - 精确匹配
  - 去掉 `/api` 前缀匹配（如 `/api/user/register` -> `/user/register`）
  - 添加 `/api` 前缀匹配（如 `/user/register` -> `/api/user/register`）
- 返回包含 `method`, `path`, `summary` 的列表

### 2. 前端修改 (`frontend/src/views/api-testing/ScenarioTestCases.vue`)

- "涉及端点"列：显示 URL 路径（而非 HTTP 方法）
- "涉及端点摘要"列：显示每个端点的摘要信息（从 `involved_endpoints_with_summary` 字段）

### 步骤 4: 确认 APIEndpoint 表中的数据

检查数据库中是否有对应的端点：

```python
# 在 Django shell 中运行
from api_testing.models import APIEndpoint
from projects.models import Project

project = Project.objects.get(name='智慧物业项目')
endpoints = APIEndpoint.objects.filter(
    method='POST',
    spec__project=project
)

for ep in endpoints:
    print(f"{ep.method} {ep.path} - {ep.summary}")
```

应该能看到类似：

```
POST /user/register - 用户注册--【作者：柠檬班】
POST /user/login - 管理端用户登录--【作者：柠檬班】
POST /community/add - 添加小区--【作者：柠檬班】
...
```

**注意路径格式**：
- 如果数据库中是 `/user/register`（没有 `/api` 前缀）
- 而测试用例中是 `/api/user/register`（有 `/api` 前缀）
- 后端代码会自动处理这种差异

## 可能的问题和解决方案

### 问题 1: AI 生成的端点路径不存在于数据库

**原因**: AI 生成的测试用例可能使用了虚拟的、不存在的端点路径（如 `/api/users/register` 而数据库中是 `/user/register`）

**解决方案**: 
- 方案A: 修改 AI 生成逻辑，确保生成的路径与数据库中的端点匹配
- 方案B: 在前端显示路径而非摘要（回退方案，已在代码中实现：`{{ endpoint.summary || endpoint.path }}`）

### 问题 2: Django 服务器没有重启

**解决方案**: 重启 Django 服务器以加载最新代码

### 问题 3: 序列化器字段没有被包含在 API 响应中

**检查**: 
1. 确认 `involved_endpoints_with_summary` 在 `APITestCaseSerializer` 的 `fields` 列表中
2. 确认 `get_involved_endpoints_with_summary` 方法存在
