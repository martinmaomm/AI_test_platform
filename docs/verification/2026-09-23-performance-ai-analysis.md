# 压测结果 AI 分析第一版验收

## 功能

已结束的正式压测详情提供「AI 分析结果」。可选择启用的 LLM，并为本次分析填写可选 P95 上限、错误率上限和 RPS 下限。目标不会改写计划。结果包含性能目标判断、AI 摘要、观测/推测、建议、引用证据及限制条件，并保存模型和时间，支持最近 20 条历史查看与失败后重新分析。

目标比较由程序完成。未配置目标、零请求、缺少指标或未完整完成的运行不会误判整体达标。错误率使用未舍入数值比较，极低但非零的错误率不能通过零错误目标。节点峰值来自采样，结束时用户数为零不被当成未发压。

输入仅保留白名单统计、有限趋势、节点资源和去重错误类型摘要；接口和节点匿名编号，再由页面对应回本地名称。模型输入不包含原始 URL、名称、变量、请求头、请求体、响应内容、断言实际值或原始错误信息。模型无工具权限。输出经过长度、JSON 结构和证据 ID 校验，页面只以转义文本展示。

任务持久化，事务提交后交由 Celery 处理；按运行行锁防止重复任务，request_id 支持请求重放。后台复查权限、模型与运行状态；排队上限 300 秒，执行上限 180 秒，超时记录可恢复为失败，晚返回不能覆盖终态。界面提交结果不确定时保留整个原请求，重复点击不会改变模型、目标或请求编号。
