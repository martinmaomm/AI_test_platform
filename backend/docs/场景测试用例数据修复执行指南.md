# 场景测试用例数据修复指南

## 问题描述

场景测试用例列表页的"涉及端点摘要"列显示的是路径（如 `/api/user/register`），而不是摘要信息（如"用户注册--【作者：柠檬班】"）。

## 原因分析

有两种可能的原因：

1. **路径不匹配**: 测试用例中存储的端点路径与数据库中 `APIEndpoint` 表的路径不一致
   - 例如：测试用例存的是 `/api/user/register`
   - 但数据库中存的是 `/user/register`

2. **数据未提取**: 旧的测试用例在创建时没有提取 `involved_endpoints` 字段

## 🚨 如果还是显示路径而不是摘要

### 情况A: 后端没有找到匹配的端点

**检查方法**：
```bash
# Django shell
python manage.py shell
```

```python
from api_testing.models import APITestCase, APIEndpoint

tc = APITestCase.objects.get(id=136)
print(f"测试用例端点: {tc.involved_endpoints[0]}")

# 检查数据库中的端点
ep = APIEndpoint.objects.filter(
    method='POST',
    path='/user/register',
    spec__project=tc.project
).first()

print(f"数据库中的端点: {ep}")
if ep:
    print(f"摘要: {ep.summary}")
```

**解决方案**：
- 如果数据库中没有对应的端点，说明 API 规范文件可能有问题
- 需要重新上传 Swagger 文档

### 情况B: 序列化器没有返回正确的数据

**检查方法**：查看 Django 服务器终端输出，应该有调试信息：

```
========== DEBUG: 开始处理测试用例 #136 ==========
测试用例标题: 智能场景: 请针对管理用户的注册、登录...
项目: 智慧物业项目
涉及端点数量（去重前）: 8

测试: POST /api/user/register
  尝试去掉/api前缀: /user/register
  ✓ 去掉/api前缀匹配成功: 用户注册--【作者：柠檬班】
...
```

**解决方案**：
- 如果没有看到调试信息，说明序列化器没有被调用
- 请确保 Django 服务器已重启
- 清除浏览器缓存并刷新
