# MCP 单一配置验收

日期：2026-09-15

## 本次范围

- 全平台仅一份 Playwright MCP 配置。首次可添加；已有配置仅编辑、启停、刷新工具，不支持删除或追加其他版本。
- JSON 只接受一个 `playwright` 服务。管理员权限保持不变，不改网页探索及任务调度。
- 数据库固定槽位的唯一约束、检查约束共同防止重复创建；接口重复提交返回 409，删除返回 405。
- `0004_mcpconfiguration_singleton` 遇到多条历史配置时先报错停止，不自动删除数据。

## 已验证

- 后端隔离回归：51 项通过，包括重复创建、模拟并发冲突、停用后不可新增、越权、编辑及工具清单状态。

- 前端单元测试：325 项通过；生产构建通过。
- 真实 Vue + Django 浏览器验收：首次创建、第二标签页提交冲突恢复、编辑 Monaco JSON、启停、工具列表、空工具清单、检测失败、加载失败重试、禁止删除，以及 390px 页面/编辑弹窗宽度全部通过。
- 浏览器验收采用临时数据库和本地 stdio MCP 工具清单服务，不调用 LLM、不访问被测业务网站。
- 当前 MariaDB 已执行 0004；对原字段及工具记录做完整摘要比对，一份配置及 33 条工具记录未变化。
