## 本次代码修复

### 精确提取与写入前保护

支持小范围、确定性的列表等值筛选，例如：

```text
body.data[?(@.name == ${unique_name})][0].id
body.data.list[?(@.name == "${unique_name}")][0].id
```

- 条件变量按数据绑定，不执行 Python、`eval` 或任意表达式；数字、字符串、布尔值区分类型。
- 对象点路径、带引号的键、数字索引、`.0` 数字点索引保留。拒绝残余语法、隐式数组字段投影、复合逻辑、通配符、递归、切片、动态索引和函数。
- 用于提取时，筛选必须恰好匹配一条；零条或多条均保留失败响应并停止后续步骤，不回退到第一条。
- 普通断言可对筛选结果执行 `length=1` 或 `length=0`，用于验证存在或删除后不存在；不存在验证不应继续提取 ID。
- 追踪提取变量流向后续写请求。未经限定的多行数组索引/数组结果若用于写入，会在提取处阻断；覆盖变量、配置别名、`extract` 转存及转存后增加数组索引均有测试。
- 平台与导出 Python 内嵌同一执行核心，不引入新的 JSONPath 依赖。
- 此保护只解决明确的数组来源歧义，不是通用业务权限证明，也不能保证模型写死的某个 ID 一定属于本轮数据。仍需用唯一业务字段核对操作对象。

生成提示同步说明提取、分页范围、比较器和运行时变量；候选检查会在 HTTP 前校验提取条件中的变量。可视编辑器增加选择器说明，并补齐长度、类型、不包含、大小等比较器选项。

### 场景规划重复分类

同一端点可能既是测试目标，也是后续步骤的前置用法。原先若它同时出现在 `endpoint_ids` 与 `dependency_endpoint_ids`，整份计划被拒绝。

现在只移除重复的依赖标记，**保留业务目标与认证集合不变**；越界、非法类型及剩余依赖缺乏证据仍拒绝。不按网站名称或登录 URL 硬编码豁免鉴权。
