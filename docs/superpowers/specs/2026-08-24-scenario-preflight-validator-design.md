# AI 场景生成预检查器设计

## 背景

当前 AI 场景生成器已经通过 Pydantic 校验 HttpRunner JSON 的基本结构，但生成结果仍可能出现变量未定义、变量在定义前使用、提取路径格式不合法、断言格式不完整等语义问题。这些问题通常要等到用户手工调试时才暴露。

## 目标

第一版在 AI 生成和保存之间增加一个确定性的场景预检查器，用于尽早发现高确定性的脚本问题，并在前端展示可读的检查报告。本轮在此基础上增加有限次数的 AI 自动修复，避免发现问题后直接终止流程。

## 范围

### 本次实现

- 检查全局变量、步骤变量和前序步骤提取变量的定义情况。
- 检查 `${variable}` 的使用位置，识别变量未定义和先使用后定义。
- 检查提取表达式和断言目标的基本路径格式。
- 将 APIEndpoint 中已解析的响应示例和响应 Schema 整理为接口级响应契约，并传给 AI。
- 当响应契约可用时，检查提取和断言路径是否确实存在于当前接口响应结构。
- 检查断言是否为合法的 HttpRunner 字典结构。
- 检查断言目标是否位于允许的响应根节点：`status_code`、`body`、`headers`、`cookies`。
- 生成结构化的 `errors` 和 `warnings`，随异步任务结果返回。
- 对变量、结构、路径格式等确定性错误，基于检查报告自动修复，最多执行两轮并重新校验。
- 响应契约不完整或字段未在契约中声明时作为警告，不直接阻断保存；真实调试响应再确认。
- 自动修复后仍存在错误时不保存测试用例，但保留最终脚本草稿和完整检查报告。
- 只有警告时允许保存，并在页面提示。

### 暂不实现

- 不发起真实接口请求，因此不保证某个字段在实际响应中一定存在。
- 不根据响应契约自动修改 AI 生成的脚本。
- 不让大模型自动修复并覆盖用户结果。
- 不改变现有场景执行、调试和断言逻辑。

## 设计

新增独立的 `ScenarioPreflightValidator`，输入解析后的 HttpRunner 场景字典，输出：

```json
{
  "valid": false,
  "errors": [
    {
      "step": 2,
      "kind": "undefined_variable",
      "field": "request.url",
      "variable": "user_id",
      "message": "变量 user_id 未在当前步骤之前定义"
    }
  ],
  "warnings": [],
  "summary": {
    "error_count": 1,
    "warning_count": 0,
    "step_count": 2
  }
}
```

校验器保持纯 Python、无数据库和网络依赖，方便单元测试和后续复用。AI Agent 在路径自动修正后，将已整理的响应契约传给校验器：

```text
Pydantic 结构校验
    -> API 路径自动修正
    -> 响应契约驱动生成
    -> 场景预检查
    -> 有确定性错误则 AI 修复，最多两轮
    -> 重新预检查
    -> 仍有错误则保留草稿并终止保存
    -> 无错误则保存，并返回检查报告
```

前端在生成结果区域新增“生成结果检查”卡片：错误使用红色提示，警告使用黄色提示，并展示步骤号、字段、修改建议和自动修复轮数。若最终仍有错误，页面展开显示未保存的完整脚本草稿。原有成功消息及用例保存行为保持不变。

## 校验规则

1. 全局变量来自 `config.variables`。
2. 步骤变量来自当前步骤的 `variables`，可供当前步骤请求和断言使用，但变量值不能自引用。
3. `extract` 产生的变量从该步骤完成后才可被后续步骤使用。
4. `${name}` 必须能在当前步骤执行前从上述变量集合中解析。
5. `extract` 的路径必须是非空字符串，且以 `body`、`headers`、`cookies` 或 `status_code` 开头。
6. `validate` 必须是字典列表，每条断言的值必须是至少包含目标路径和期望值的列表。
7. 断言目标必须使用上述允许的响应根节点；如果当前接口已有响应示例或 Schema，则目标字段不存在于响应契约时报告警告，由真实调试响应确认。
8. 如果当前接口没有可用的响应示例或 Schema，只能报告警告，不能凭空推断 body 字段。

## 错误处理

- 场景 JSON 无法解析或步骤结构缺失：作为错误，终止保存。
- 变量未定义、先使用后定义、路径或断言结构明显非法：作为错误，终止保存。
- 当前接口没有可用响应契约，导致无法确认响应字段是否真实存在：作为警告，允许保存。
- 当前接口有响应契约但字段不存在：作为警告，不直接终止保存，避免不完整 Swagger 文档阻断场景生成。
- 预检查器本身发生异常：记录日志并终止保存，避免保存未经检查的结果。
- 自动修复调用失败或两轮后仍有错误：记录修复历史，保留最终草稿并终止保存。

## 验收标准

- 一份包含未定义变量的 AI 场景不会写入数据库，并在生成页面展示具体步骤和变量名。
- 一份只有无法静态确认响应字段的场景可以正常保存，并显示警告。
- 一份包含未定义变量或非法断言结构的场景会触发最多两轮自动修复，并对每轮重新校验。
- 一份引用 `body.success` 但当前响应示例只有 `body.token` 的场景会显示契约警告，不因静态文档不完整直接阻断。
- 两轮修复后仍不通过的场景不会写入数据库，但页面能够查看最终脚本草稿。
- 现有合法场景生成流程、数据库保存和前端构建不受影响。
- 预检查器单元测试覆盖合法场景、未定义变量、先使用后定义、非法路径和非法断言结构。
