# WebUI 脚本生成工作区：实施与验收

用户已确认本方案并授权实施。范围仅 WebUI 生成主流程；不恢复元素库，不修改 API/App，不操作现有业务数据。

## 用户流程与责任

描述测试目标 → 自动只读探索 → 有证据的脚本草稿 → 同页编辑、配置变量、授权调试 → 保存独立用例。

- 用户提供业务目标、成功标准、环境、登录条件与允许的数据范围，不提供 DOM/定位器。
- AI 选择探索动作、整理页面证据与编写代码；平台负责边界、预算、证据完整性和状态流转。
- 生成和静态检查不等于运行通过。只读探索不提交新增、编辑、删除；调试由用户明确发起，仍使用现有 Chromium/Python 执行器。
- 模块仅分类；用例独立；套件变量覆盖用例变量。保存后的重复执行不调用模型。

## 探索闭环

1. 先检查页面/步骤证据，再调用脚本生成器。模型最终回复不是完成依据。
2. 页面可观察缺失项进入有限定向补充，尽量使用同一浏览器会话；共享预算，不绕过取消、登录失败、重复操作或工具错误。
3. 只向用户提出明确的业务/权限/数据范围决策；页面不可达、无权限、预算耗尽或证据不足必须显示具体阻塞，不转换为 DOM 问卷。
4. 保留任务级安全观测/checkpoint，不依赖最后一个大 JSON 才留下成果，不保存原始凭据/HTML；不复活元素库。
5. 只读可以观察表单和入口，不证明 CRUD 提交/清理成功。需要实际数据才能观察的内容必须说明边界，不伪造定位器。

## 草稿、调试与保存

- 生成工作区拥有独立 revision、变量定义、调试结果和修复状态，与生成阶段分离。
- PATCH draft 保存编辑；语法错误可以保留在工作区，但不得执行。保存到用例仍遵守严格脚本契约。
- POST debug 必须显式确认，创建执行记录但不创建测试用例；复用原有错误摘要、失败截图、日志和报告。
- 调试锁定草稿版本、环境与配置；旧任务结果不得覆盖新稿。改稿或变量变化使当前验证失效。
- 敏感运行值只短期缓存，不能放进任务参数、持久化变量或浏览器本地存储。标记为敏感的定义默认值为空。
- 可保存“未验证草稿”；“调试通过”要求当前版本的真实通过结果。保存幂等不能阻止后续修订，也不能静默覆盖用例管理中另行编辑的版本。
- 请求修复是显式、有限的动作；不自动重跑业务写入。修复不得删断言、吞异常、改变成功标准或数据范围；没有定位证据时返回人工处理提示。

## 分工和验证

- 探索控制与证据判断：独立 Terra 实施。
- 工作区 API、异步调试/修复、保存版本：独立 Terra 实施。
- 前端编辑/变量/调试/结果工作区：独立 Terra 实施。
- 主 Agent：接口协调、保守修复策略、交叉审查、离线集成回归和提交。

验收重点：登录后提前结束不能当完成；页面问题不转用户问卷；真实业务决策可确认；补充探索不重置预算；取消及时终止；未运行不标通过；运行须明确确认；旧 revision 不覆盖；保存/二次编辑不丢稿；跨项目/他人记录权限拒绝；失败截图/log可查看；变量优先级不回退。

使用网络隔离的 SQLite 测试、mock MCP/模型/执行器，以及前端测试和构建。不得默认连接 NAS 运行测试或迁移。不以离线通过宣称第三方模型和真实站点已端到端通过。

## 部署与回退

新增工作区 JSON 字段，迁移为 `0016_webuiscriptgeneration_workspace`，仅加字段，保留旧记录。先在 backend 虚拟环境执行 `python manage.py migrate web_testing`，然后重启后端和 Celery。前端开发模式刷新，生产模式重新构建。无需重装依赖。

`backend/env.example` 新增可选的 `WEBUI_EXPLORATION_TOTAL_TIMEOUT_SECONDS=600`；实际 `.env` 未改动。未设置时沿用 `AITS_LLM_TIMEOUT_SECONDS`，再回退到 600 秒；探索总时限约束初次及一次定向补探索，关闭会话另留最多 10 秒。

提交不含浏览器 ZIP，不自动 push。回退优先恢复本次提交前的应用代码，保留新增数据库列和数据，不执行破坏性逆向迁移。正在运行的新任务先等结束或由用户停止，避免新旧代码混跑。

## 本次验证结果

- 后端离线回归：232 项通过；包括真实本地 LangGraph 调度配合 mock MCP/模型的工具边界测试，以及工作区版本、权限、重复投递、缓存故障、保存防覆盖、修复范围测试。
- 前端 `npm run test:unit`：12 项通过，涵盖本地编辑保护、过期响应隔离、明确调试与保存模式；`npm run build` 通过，仍有原有大体积 chunk 提示。
- 迁移漂移检查通过；未在 NAS 执行迁移，SQLite 模型测试不能替代 MariaDB 迁移验收。
- 使用 browser skill 的本地模拟页面验收了编辑、添加变量、取消/确认真实调试、运行中锁定、失败摘要和修复入口。该检查发现并修正了 Monaco 导致的横向撑宽；1280px 视口内容宽度恢复为 1280px。
- 未调用真实 LLM、未登录业务网站、未连接 NAS DB/Redis；真实生成及数据操作效果仍待用户重启后试跑。
