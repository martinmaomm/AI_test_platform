# API 对话工作区：按来源拆分页面

状态：已实施，隔离回归与浏览器验收通过，见 [验收记录](../api-workspace-source-pages-acceptance-2026-09-09.md)。

## 用户流程

左侧仍只有「API 对话工作区」入口，默认进入「从接口文档生成」。页内的两个标签使用独立路由：

- `/api-testing/workspace/documents`：选择已有、已解析的 Swagger / API 文档，选择接口和模型，描述目标，生成并验证。
- `/api-testing/workspace/browser`：默认展示探索任务列表，不自动恢复最近的生成工作区。2026-09-15 补充分离以下子视图：
  - `?view=new`：独立的新建探索表单。
  - `?discovery_id=<任务 UUID>`：该次探索详情、时间和接口样本。
  - `?workspace_id=<工作区 ID>`：该次交接结果的场景生成、调试和保存。

列表按创建时间倒序展示，每次探索显示其关联生成结果。「确认接口并生成场景」先完成样本交接，再打开生成前确认框；必须明确确认后才调用模型和执行接口。新建、详情、场景生成不会同时混在一个页面。刷新和前进后退根据 URL 恢复对应内容，不重新启动探索或生成。

旧 `/api-testing/workspace` 默认指向文档页面。携带工作区、用例或接口 ID 的入口根据真实来源定位，不依赖之前访问的标签。浏览器刷新保留当前来源页面；文档上传只作为无可用文档时的辅助入口。

## 实施边界

1. 两个页面分别加载和管理自己的工作区列表，网页页不加载或显示 Swagger 选择器，文档页不加载浏览器任务。
2. 浏览器样本交接后保留来源名、任务标识及相关接口范围，继续复用现有场景生成、编辑、调试、修复、保存和 Python 导出。
3. 后端从关联规范的 `spec_type` 推导只读 `source_type`、`source_name`、`source_task_id`；子场景跟随根工作区来源。不依赖会被任务状态覆盖的 `generation.source`，不新增数据库字段。
4. 工作区列表支持按来源过滤，仍保留现有用户和项目权限；不接受客户端任意声明来源。
5. 切换来源时保护未保存草稿、配置和未提交描述。离开页面只停止轮询并隔离过期响应，不取消已提交的后台任务。

不重写 requests 执行引擎，不清理数据库，不迁移或重建已有工作区，不新增依赖。

## 验收口径

- 默认文档入口可直接选择已有规范，不跳到上传页；网页页无 Swagger 下拉框。
- 两类来源列表相互隔离，交接、刷新、显式 ID 深链后来源仍然正确。
- 未保存编辑有离开确认；切换页面不发送取消任务请求，不把旧请求结果写入新页面。
- 网页探索的启用开关、禁用模型过滤、授权确认、取消、部分失败证据、分页、50 个接口组上限保持有效。
- 运行隔离数据库单元测试、前端测试与构建，以及真实 Vue + Django 本地浏览器验收。模型和被测网站使用可控 fixture；不据此声称真实第三方模型已验证。

## 发布与回退

部署前后端同一版本，重启后端加载来源接口；前端开发模式刷新页面，生产模式发布新构建。本次不新增迁移。发生问题时可回退本次代码提交；已有用例和工作区数据不删除。
