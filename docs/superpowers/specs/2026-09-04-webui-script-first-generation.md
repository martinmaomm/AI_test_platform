# WebUI 单智能体、脚本优先生成

## 已批准的范围

替换生成内核，保留项目、业务模块、独立用例、套件、变量优先级和统一 Python Playwright 执行器。无需旧生成记录兼容，不删除用户当前业务数据。

用户目标 → 本地轻量任务摘要 → 环境/模型/MCP 预检 → 一个智能体连续探索与编写 Python → 静态检查 → 用户检查、调试、保存。

不再要求前置模型生成完整 ScenarioPlan，不要求智能体提交 event_id 最终路径，不以确定性编译 AST 一致性作为草稿交付条件。

## 职责与接口

- `generation_brief.py`：保留原始目标，不猜测页面元素、成功文字、变量或登录流程。
- `script_exploration_agent.py`：一名智能体、连续 MCP 会话，通过 `aits_save_script` 多次保存完整 Python 草稿；平台自动保留动作、页面信息、模型最终说明和结束原因。
- `generation_orchestrator.py`：任务归属、状态、增量持久化、取消/过期任务隔离；不伪装异常为最终定稿缺失。
- `draft_quality.py`：检查语法、入口、未定义引用、危险调用及待完成工作；不宣称静态检查能够证明业务通过或隔离任意 Python。
- 工作区：保持版本冲突保护；草稿检查、真实调试和保存分别操作。

使用现有表和状态字段，新摘要与快照 `schema_version=5`。快照包含 `events`、页面观察、统计、`termination_reason`、`final_message` 及 `artifact`。`artifact` 保存草稿版本、完成度、已完成/未完成步骤、变量和有界历史。

## 必须保持的语义

1. 草稿已生成、目标覆盖完整、真实调试通过是不同事实。
2. 未探索步骤保留 `# AITS_PENDING_STEP: {"reason":"..."}`；未知断言保留 `AITS_PENDING_ASSERTION`。有任何待完成项时，即使部分断言执行成功，也只能是验证未完成。
3. 普通固定值可直接使用；要求唯一的数据在每次运行时生成，用户指定 `time.time_ns()` 时遵循。凭据可由配置或测试明文提供，保留“请勿使用生产账号”提醒。
4. 不以猜测的按钮/定位器补齐未探索流程；代码修改不能通过删除断言或吞掉异常制造通过。
5. 增量草稿在失败、超时、取消后仍保留。持久化失败不得返回“已保存”。旧 worker 不能覆盖用户编辑或新任务状态。
6. 基于已有证据的“仅整理脚本”不启动 MCP，不重复业务写入；缺少证据的步骤继续标记未完成。
7. 智能体结束说明和原始错误类别持久化；模型异常、浏览器操作失败、超时和未完成目标不能混为一个报错。
8. 工具成功不等于业务成功；观察工具自身找不到元素属于工具失败，网页正常展示的“暂无数据/not found”属于业务内容。
9. 保留总时限、模型/工具预算、项目权限、环境约束和高风险操作限制。中途自动恢复不得重新提交结果未知的写入。
10. 首次浏览器调用前保存仅含已知入口的基础草稿，显式标记尚未探索，不编造页面元素。模型后续保存的草稿替换它；入口草稿没有断言，不能算作测试通过。

## 验收与回退

离线覆盖：无 v4 定稿也能交付，partial 保存与调试状态、增量版本、取消隔离、异常原因、code-only 不打开浏览器、待完成步骤不假绿、前端 dirty 编辑保护。

真实验收应额外验证：真实模型与 Playwright MCP 生成、生成源码通过 Python 浏览器回放、至少两种页面/场景、重复执行唯一数据、失败保留草稿。真实验证必须说明所用页面与运行边界；离线 mock 不能替代真实验收。

不自动重启用户服务，不执行破坏性迁移。回退使用本次提交的反向提交并重启后端/Celery；不承诺新旧生成快照互通。
